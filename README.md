# nvim

neovim god config 🧙

based heavily on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim)

needs neovim 0.12+ and tree-sitter cli

on macos:

```sh
brew install neovim tree-sitter-cli ripgrep
```

toolchains: clang/clang++, go, python/uv + node/npm, cargo/rustc.

space is leader. `space f` files, `space g` grep, `space r` run.
